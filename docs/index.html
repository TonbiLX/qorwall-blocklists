💡 Niçin başka bir blocklist?

Mevcut DNS blocklist'leri (StevenBlack, Hagezi, OISD) global odaklı — milyonlarca domain ama Türkçe streaming (BluTV, Exxen, Tabii), yerel bahis siteleri (mobilbahis, betpas) ve TR e-ticaret eksik.

QorWall Blocklists bu boşluğu doldurur: TR + Global birleşik, kategori-bazlı, az false-positive, CDN'ler dahil (gerçek block için kritik), CC0 lisans.

🚀 Kullanım

🛡️

QorWall

  1. İçerik Filtreleri sayfası
  2. Kategori → Düzenle
  3. + Yeni Liste Ekle
  4. URL yapıştır → Domain List
  5. Refresh: 24h
🕳️

Pi-hole

  1. Adlists sayfası
  2. Add a new adlist
  3. URL yapıştır
  4. Tools → Update Gravity
🛡️

AdGuard Home

  1. Filters → DNS blocklists
  2. Add blocklist → Custom
  3. URL yapıştır
  4. Save
